## A few things I've built 🚀

### 📰 [News Article Classification](https://github.com/matteosisti/news-article-classification-robust-ensembles)

A full NLP pipeline that moves from TF-IDF baselines to RoBERTa, DeBERTa, and robust ensembles.

**The fun part:** it finished **1st out of 220 participants** with a **0.761 Macro-F1** score.

### 🎬 [Neural Ranking Under Noise](https://github.com/matteosisti/neural-ranking-under-noise)

A Two-Tower recommendation system trained on MovieLens 20M, plus an investigation into what happens when training data gets noisy.

**The fun part:** an **11× training speedup** and some surprising evidence that random noise can behave like regularization.

### 🧩 [segdatakit](https://github.com/matteosisti/segdatakit)

A toolkit for converting and validating semantic-segmentation datasets without changing a single pixel.

It supports Zarr, WebDataset, PyTorch, and optional NVIDIA DALI loading — because downloading 30 GB of PNGs every Colab session gets old quickly.

### 💳 [Credit Card Fraud Detection](https://github.com/matteosisti/anomaly-detection-credit-card-fraud)

An unsupervised anomaly-detection pipeline built around Isolation Forest and a realistically imbalanced dataset.

**Result:** **0.95 ROC-AUC**, with the usual precision-vs-recall trade-offs that make fraud detection interesting.

### 📈 [Retail Demand Forecasting](https://github.com/matteosisti/Retail-Demand-Forecasting-with-LightGBM)

A forecasting pipeline combining lag features, rolling statistics, promotions, holidays, and external regressors.

**Result:** LightGBM reached a validation **RMSLE of 0.7953**.
